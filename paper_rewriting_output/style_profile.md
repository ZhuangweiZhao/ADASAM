# Style Profile

- **Audience:** ML/CV reviewers familiar with segmentation and parameter-efficient adaptation.
- **Tone:** concise, empirical, skeptical of architectural novelty without ablation.
- **Argument unit:** question -> matched evidence -> effect size -> boundary.
- **Numbers:** always state metric, budget, seed count and whether values are mean/std.
- **Figures:** label-efficiency curves, paired gain plots, Pareto plots only when timing is comparable.
- **Terminology:** call the task label-efficient semantic segmentation, not novel-class few-shot segmentation.
- **Prohibited overclaims:** real-time, SOTA, universal robustness, causal bottleneck, or sparse acceleration without direct evidence.
- **Negative results:** include them in the main narrative when they invalidate an intended mechanism.
